# cp_measure v0.2.0 performance report

This report separates two kinds of evidence:

1. a direct **v0.1.19 vs v0.2.0** comparison using the same benchmark process and dependency versions; and
2. **incremental PR benchmarks** captured by the CI benchmark workflow while v0.2.0 was developed.

`speedup = v0.1.19 time / v0.2.0 time`; values above 1 are faster in v0.2.0.
These synthetic results characterize this benchmark matrix, not every microscopy
workload. In particular, speedups should not be multiplied across PRs.

## Method

The direct comparison used `.github/scripts/benchmark.py` from the v0.2.0 release
branch for both versions.

- Versions: tag `v0.1.19` vs release commit `3700173`
- Images: synthetic 2D images of `256x256`, `512x512`, and `1024x1024`
- Object counts: 16, 64, and 256
- Random seeds: 0, 1, and 2
- Timing: one warm-up and three measured repetitions per seed
- Reported cell value: median across all repetitions and seeds
- Threads: BLAS, OpenMP, NumExpr, and Numba restricted to one thread
- Python: 3.12.7
- Dependencies shared by both environments: NumPy 2.5.2, SciPy 1.18.0,
  scikit-image 0.26.0, centrosome 1.3.3, and mahotas 1.4.18
- Machine: AMD Ryzen Threadripper PRO 7995WX, NixOS x86_64
- Run date: 2026-08-13

All 648 function/version benchmark cells completed successfully; there were no
errors or timeouts. Raw results are retained in:

- [`data/v0.2.0/v0.1.19.json`](data/v0.2.0/v0.1.19.json)
- [`data/v0.2.0/v0.2.0.json`](data/v0.2.0/v0.2.0.json)

## Direct v0.1.19 vs v0.2.0 summary

The median column is the median speedup across the nine image-size/object-count
cells. The range shows the minimum and maximum cells.

| Measurement         | Median speedup |        Range |
| ------------------- | -------------: | -----------: |
| Intensity           |     **28.07x** | 8.91–105.04x |
| Manders/Fold        |     **12.57x** |  8.47–40.47x |
| Feret               |      **4.49x** |  1.71–15.44x |
| RWC                 |      **4.37x** |  2.94–11.62x |
| Shape Zernikes      |      **3.89x** |   3.49–5.63x |
| Radial Zernikes     |      **3.41x** |   2.53–6.25x |
| Pearson             |      **3.26x** |  2.27–12.55x |
| Costes              |      **2.95x** |   1.97–6.06x |
| Granularity         |      **2.16x** |   1.92–2.33x |
| Size/shape          |      **1.34x** |   1.14–1.58x |
| Radial distribution |      **1.28x** |   1.18–1.36x |
| Texture             |      **1.04x** |   0.92–1.15x |

Texture is effectively unchanged overall and includes small regressions in two
cells. The strongest gains tend to occur at higher object counts, where v0.2.0
avoids more per-object Python/SciPy work.
